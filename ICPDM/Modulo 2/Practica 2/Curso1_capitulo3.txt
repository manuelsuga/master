data = [("Alice", "HR", 30), ("Bob", "IT", 40), ("Cathy", "HR", 28)]
columns = ["Name", "Department", "Age"]

df = spark.createDataFrame(data, schema=columns)

# Como si se creara una tabla temporal
df.createOrReplaceTempView("people")

result = spark.sql("SELECT Name, Age FROM people WHERE Age > 30")
result.show()

# Es importante ir haciendo diferentes vistas temporales para los diferentes dataframes. El acceso a estas vistas es indicando el nombre en el FROM del SQL.

# Existe la función cast(tipo) para cambiar el tipo de una columna
df = df.withColumn("Salary", df["Salary"].cast("int"))

# Ejemplo de agregación usando rdd y map:
# primero se queda solo con dos columnas, departamento y salario
rdd = df.rdd.map(lambda row: (row["Department"], row["Salary"]))

# para cada fila (solo dos columnas) se reduce las dos columnas a solo una
rdd_aggregated = rdd.reduceByKey(Lambda x, y: x + y)

print(rdd_aggregated.collect())


Mejores prácticas antes de realizar una agregración:
	- Filtrar con anterioridad.
	- Asegurarse que los datos están limpiios y con los tipos correctos.
	- Evitar usar operaciones que usen todo el dataset.
	- Elegir correctamente donde se van a realizar: si en RDD o en DataFrames (preferible)
	- usar explain() to ver la ejecución.

El uso de dataframes y SQL mejora la manipulación de datos.
